Security
Passwords: password_hash / password_verify. Legacy plaintext rows are accepted once and re-saved as a hash. Wrong email and wrong password now give the same message.
Login throttling (my addition): 5 failures per account or 25 per IP in 15 minutes, tracked in a login_attempts table.
Sessions: session_regenerate_id on login, HttpOnly, SameSite=Lax, Secure on HTTPS, strict mode, 2-hour idle timeout.
Auth guards: require_student(bool $json) and require_staff(bool $json). They return 401 or 403 as JSON for fetch endpoints and redirect to the login page for page loads. Every dormer and staff endpoint uses them.
CSRF: csrf_require() is lenient by default. It rejects a foreign Origin or Referer, requires a valid token if one is sent, and accepts requests with no token unless CSRF_ENFORCE=1. Details are in API.md.
Payment upload: finfo MIME check plus getimagesize, 5 MB cap, random filenames, and .htaccess that disables PHP and allows only jpg/png.
Config and errors: DB settings come from DB_HOST, DB_PORT, DB_USER, DB_PASS, DB_NAME, either as environment variables or connection/.env, defaulting to localhost/root/empty. Errors go to logs/php-error.log, never to the browser. die() is replaced by JSON or a small HTML result page.
Prepared statements: the existing queries already used them, and all new ones do.
